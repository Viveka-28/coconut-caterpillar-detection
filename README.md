# Coconut Caterpillar Detection System

Transformer-Based Deep Learning Framework for Caterpillar Infestation Detection in Coconut Trees.

## Features
- EfficientNetV2B0 + Vision Transformer
- HSV Segmentation
- Android Application
- Offline TFLite Inference
- Tamil + English Support
- Real-time Detection

## Accuracy
97.02%

## Technologies Used
- TensorFlow
- TensorFlow Lite
- Android Studio
- Java
- OpenCV
